# 💡 SENAI - Lógica de Programação

Este repositório contém exercícios e atividades desenvolvidas durante o curso de **Lógica de Programação** no **SENAI**. Aqui foram abordados os **conceitos básicos de desenvolvimento web**, com foco em:

- 🧠 **Lógica de programação**
- 🌐 **HTML** (estrutura)
- 🎨 **CSS** (estilo)
- ⚙️ **JavaScript** (interatividade)

---

## 📚 O que aprendi

Durante este módulo, aprendi a:

- Criar páginas HTML com títulos, listas, imagens e links;
- Estilizar páginas com CSS, aplicando cores, fontes e layouts;
- Usar JavaScript para interações básicas, como botões, condições e estruturas de repetição;
- Aplicar conceitos de variáveis, operadores, funções e eventos.
